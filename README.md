# MHDRM Data Readiness Assessment Prototype Tool
A Streamlit prototype for screening cross-site data compatibility before beginning a healthcare multimodal federated learning (MMFL) initiative.

The tool operationalizes the seven pillars of the Multimodal Healthcare Data Readiness Model (MHDRM):

- Modality availability
- Data quality and completeness
- Population representativeness
- Standardization and interoperability
- Cross-modal alignment
- Privacy and security by modality
- Provenance and governance

### Features
- Records the proposed MMFL use case and participating sites
- Applies evidence-based response anchors to each MHDRM pillar
- Calculates pillar, category, and overall compatibility scores
- Flags critical deficiencies and insufficient evidence
- Generates a downloadable PDF assessment report

### Limitations
This application is an early-stage academic prototype intended for preliminary preimplementation screening. Its questions, scoring thresholds, and classifications have not been empirically validated and should not be interpreted as certification that an MMFL initiative will succeed.
